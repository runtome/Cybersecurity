# CTF Write-Ups

Documented solutions to CTF challenges and platform machines. Each write-up follows the standard template — use `template-writeup.md` when starting a new write-up.

## Index

| Platform | Write-Ups |
|----------|-----------|
| [HackTheBox](./htb/) | Machine write-ups (retired machines only) |
| [TryHackMe](./thm/) | Room write-ups |
| [picoCTF](./picoctf/) | Challenge write-ups by category |
| [Other Platforms](./other/) | CTFtime events, NahamCon, ICTF, etc. |

## How to Add a Write-Up

1. Copy `template-writeup.md` to the appropriate subfolder
2. Rename it: `machine-name.md` or `challenge-name.md`
3. Fill in all sections — do not skip "Lessons Learned"
4. Add an entry to this README index table

## Write-Up Standards

- Include the **exact commands** used, not just descriptions
- Capture a **screenshot of each flag** before submission
- Document **failed attempts** — what you tried and why it didn't work
- Note the **intended path** vs any unintended paths you discovered
- Keep spoilers behind a `<details>` block if sharing publicly before a machine retires
